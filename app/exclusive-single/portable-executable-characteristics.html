0x1 1 Image only, Windows CE, and Microsoft Windows NT and later. This indicates that the file does not contain base relocations and must therefore be loaded at its preferred base address. If the base address is not available, the loader reports an error. The default behavior of the linker is to strip base relocations from executable (EXE) files.
0x2 2 Image only. This indicates that the image file is valid and can be run. If this flag is not set, it indicates a linker error.
0x4 4 COFF line numbers have been removed. This flag is deprecated and should be zero.
0x8 8 COFF symbol table entries for local symbols have been removed. This flag is deprecated and should be zero.
0x10 16 Obsolete. Aggressively trim working set. This flag is deprecated for Windows 2000 and later and must be zero.
0x20 32 Application can handle > 2-GB addresses. 应用程序可以处理大于2GB的地址。
0x40 64 This flag is reserved for future use. 这个标志位保留供未来使用。
0x80 128 Little endian: the least significant bit (LSB) precedes the most significant bit (MSB) in memory. This flag is deprecated and should be zero. 小端序：在内存中低位在前高位在后。这个标志位已经废弃，应该为零。
0x100 256 Machine is based on a 32-bit-word architecture. 机器基于32位字长的架构。
0x200 512 Debugging information is removed from the image file. 调试信息从这个镜像文件中移除了。
0x400 1024 If the image is on removable media, fully load it and copy it to the swap file.
0x800 2048 If the image is on network media, fully load it and copy it to the swap file.
0x1000 4096 The image file is a system file, not a user program. 这个镜像文件是一个系统文件，不是用户程序。
0x2000 8192 The image file is a dynamic-link library (DLL). Such files are considered executable files for almost all purposes, although they cannot be directly run. 这个镜像文件是一个动态链接库。这样的文件在几乎所有用途下都被认为是可执行的，尽管它们不能直接运行。
0x4000 16384 The file should be run only on a uniprocessor machine. 这个文件应该仅在单处理器的机器上运行。
0x8000 32768 Big endian: the MSB precedes the LSB in memory. This flag is deprecated and should be zero.
